# ATLAS — Iran Options Intelligence

موتور تحلیل بازار اختیار معامله ایران. داده را از TSETMC می‌گیرد، نوسان ضمنی و
Greeks و معیارهای نقدشوندگی را خودش محاسبه می‌کند، فرصت‌ها را رتبه‌بندی می‌کند و
استراتژی می‌سازد و آزمون می‌کند.

## اجرا

```bash
pip install -r requirements.txt
streamlit run app.py
```

هیچ پکیج شخص‌ثالثی برای داده لازم نیست. هم داده زنده و هم تاریخچه مستقیماً
از Endpointهای عمومی خود TSETMC گرفته می‌شوند.

## شروع

۱. **مرکز داده ← دریافت بازار** → «دریافت و پیش‌نمایش» → «تأیید و ذخیره».
   تاریخچه دارایی‌های پایه همان‌جا خودکار گرفته می‌شود.
۲. برای بک‌تست، **مرکز داده ← تاریخچه** با گزینه «دارایی پایه + قراردادها».
   یا مستقیماً از خود صفحه بک‌تست دکمه دریافت تاریخچه را بزنید.

نیازی به ذخیره دستی Snapshot روزانه نیست؛ تاریخچه از سرویس فراخوانی می‌شود.

## منابع داده

| منبع | چه می‌دهد |
|---|---|
| TSETMC (`GetInstrumentOptionMarketWatch`) | قیمت، حجم، مظنه و عمق، موقعیت باز و OI دیروز، اندازه قرارداد، قیمت دارایی پایه |
| TSETMC (`GetClosingPriceDailyList`) | تاریخچه روزانه هر ابزار بر اساس InsCode |
| آپشن‌گر (اکسل) | مسیر اضطراری وقتی سرویس‌ها در دسترس نیستند |

**دریافت خودکار وجود ندارد.** هیچ Polling، هیچ تایمر، هیچ درخواستی هنگام
بالا آمدن برنامه. داده فقط با کلیک شما گرفته می‌شود.

### منبع هر پارامتر

تب **مرکز داده ← منبع پارامترها** جدول کاملی دارد که برای هر پارامتر نشان
می‌دهد از کدام فیلد API آمده یا با چه فرمولی ساخته شده، به‌علاوه پوشش واقعی
آن روی داده موجود. اگر عددی مشکوک بود، از همان‌جا معلوم می‌شود مشکل از
سرویس است یا از محاسبه.

## آنچه ATLAS خودش محاسبه می‌کند

TSETMC نوسان ضمنی و Greeks نمی‌دهد. ATLAS آن‌ها را می‌سازد:

- **IV** با حل معکوس Black-Scholes اروپایی. اولویت قیمت: میانه مظنه ← آخرین معامله ← پایانی.
- **Greeks** کامل، **ارزش ذاتی و زمانی**، **وضعیت ITM/ATM/OTM**.
- **تغییر موقعیت باز** از `oP` و `yesterdayOP` — بدون نیاز به Snapshot دیروز.
- **اسپرد و عمق مظنه**، **نسبت حجم به OI**، **ارزش زمانی روزانه**.
- **بازده دریافتی و سالانه‌شده**، **نقطه سربه‌سر و فاصله تا آن**.
- **HV، IV Rank، IV Percentile** از تاریخچه.
- **امتیاز فرصت** و **پایه امتیاز** (چند درصد از مؤلفه‌ها قابل محاسبه بوده).

## اصول

**داده غایب هرگز صفر نمی‌شود.** `حجم = ۰` یعنی امروز معامله نشده؛ `حجم = —`
یعنی سرویس آن را نداده. این دو در کل محصول از هم جدا می‌مانند.

**قرارداد غیرقابل‌معامله فرصت نیست.** قراردادی که نه موقعیت باز دارد و نه
معامله شده، از فهرست فرصت‌ها حذف می‌شود.

**رتبه نسبی روی داده یکنواخت بی‌معناست.** اگر همه قراردادهای یک گروه حجم صفر
داشته باشند، رتبه صدکی محاسبه نمی‌شود — وگرنه همه «صدک ۱۰۰» می‌شدند.

**میانه به‌جای میانگین برای IV.** قراردادهای کم‌قیمت IVهای ۲۰۰٪+ می‌سازند و
میانگین را غیرواقعی بالا می‌برند.

**مؤلفه غایب امتیاز را صفر نمی‌کند.** وزن‌ها بازتوزیع می‌شوند و «پایه امتیاز»
کاهش می‌یابد.

**محاسبه در `core`، نمایش در `ui`.** هیچ فرمول مالی در فایل‌های صفحه نیست.

## فیلترها و ستون‌های مشتق

**اسکنر** علاوه بر فیلترهای معمول، این‌ها را هم دارد: «فقط معامله‌شده امروز»
(پرکاربردترین فیلتر در بازاری که چهارپنجم قراردادهایش روزانه معامله نمی‌شوند)،
حداقل رشد موقعیت باز، حداکثر اسپرد، و حداقل بازده سالانه.

**زنجیره اختیار** در «ستون‌های پیشرفته» تغییر OI، اسپرد، عمق مظنه، نسبت
حجم به OI، ارزش زمانی روزانه، بازده سالانه، و نقطه سربه‌سر را نشان می‌دهد.

## تست

```bash
python3 tests/run_all.py
```

تست‌ها روی نمونه واقعی پاسخ TSETMC (`tests/fixtures/`) اجرا می‌شوند و شبکه
لازم ندارند. `verify_rendered.py` مقادیری را می‌سنجد که واقعاً در HTML صفحات
رندر می‌شوند، نه فقط خروجی توابع.

## محدودیت‌ها

- **موقعیت باز تاریخی وجود ندارد.** Endpoint تاریخچه فقط OHLCV می‌دهد و هیچ
  منبع عمومی دیگری هم OI روزهای گذشته را ندارد؛ `None` می‌ماند، نه صفر.
  از امروز به بعد با هر Snapshot انباشته می‌شود.
- **تاریخچه قراردادها کند است** — یک درخواست به‌ازای هر نماد.
- **مظنه فقط برای بخشی از قراردادها** موجود است، پس اسپرد و نقدشوندگی برای
  بقیه با اطمینان کمتری محاسبه می‌شود.
- بک‌تست مالیات و لغزش قیمت را مدل نمی‌کند.
